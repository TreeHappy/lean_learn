# Bibliography

Sources for the four concepts added to the Lean code:

* affine connection — `lean/Brane/Connections.lean`;
* parallel transport — `lean/Brane/ParallelTransport.lean`;
* connection on a vector bundle — `lean/Brane/Connections.lean`;
* Lie algebra — `lean/Brane/LieAlgebra.lean`.

The prose introductions live in [`docs/connections.md`](docs/connections.md)
and [`docs/lie-algebra.md`](docs/lie-algebra.md).

The machine-readable bibliography is [`references.bib`](references.bib);
this page is the human-readable index of the same sources.

## BibTeX

The machine-readable bibliography is [`references.bib`](references.bib). It
contains one entry per source listed above (encyclopedia articles, lecture
notes, papers, books, and the tooling used by the repository), with `url`
fields wherever an online copy exists.

```bibtex
% cite the whole bibliography with
\nocite{*}
\bibliography{references}
```

Key names follow the pattern `wiki…`, `mathworld…`, `nlab…`, `eom…` for the
encyclopedia articles, and author–year (`koszul1950`, `ambroseSinger1953`,
`lee2018`, …) for papers and books. See `references.bib` for the full list.
